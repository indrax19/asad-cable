                          API ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════


1️⃣  CREATE USER
────────────────────────────────────────────────────────────────────────────

  POST /functions/v1/admin-users
  
  Request:
  {
    "action": "create",
    "email": "user@example.com",
    "password": "password123",
    "profile": {
      "name": "User Name",
      "role": "dealer|customer",
      "status": "active",
      "phone": "+92..."
    }
  }
  
  Response:
  { "id": "user-uuid" }


2️⃣  UPDATE USER
────────────────────────────────────────────────────────────────────────────

  POST /functions/v1/admin-users
  
  Request:
  {
    "action": "update",
    "userId": "user-uuid",
    "email": "newemail@example.com",
    "password": "newpassword123",
    "profile": { "name": "Updated Name" }
  }
  
  Response:
  { "id": "user-uuid" }


3️⃣  DELETE USER
────────────────────────────────────────────────────────────────────────────

  POST /functions/v1/admin-users
  
  Request:
  {
    "action": "delete",
    "userId": "user-uuid"
  }
  
  Response:
  { "id": "user-uuid" }

═══════════════════════════════════════════════════════════════════════════════
                        DATA FLOW
═══════════════════════════════════════════════════════════════════════════════


CREATE USER FLOW:
────────────────────────────────────────────────────────────────────────────

  Frontend (Dealers/Users page)
      ↓
  supabase.functions.invoke("admin-users")
      ↓
  Edge Function receives request
      ↓
  Verify JWT token
      ↓
  Check admin role
      ↓
  Create auth user (Supabase Auth)
      ↓
  Create database profile (users table)
      ↓
  Return user ID
      ↓
  Frontend stores/displays


UPDATE USER FLOW:
────────────────────────────────────────────────────────────────────────────

  Frontend
      ↓
  supabase.functions.invoke("admin-users")
      ↓
  Edge Function
      ↓
  Update auth (if email/password)
      ↓
  Update database profile
      ↓
  Return success
      ↓
  Frontend updates UI

                      ERROR CODES
═══════════════════════════════════════════════════════════════════════════════


❌ 401 Unauthorized
   → User not logged in
   → Solution: Login first

❌ 403 Forbidden
   → User is not admin
   → Solution: Use admin account

❌ 400 Bad Request
   → Invalid data format
   → Solution: Check JSON format

❌ Email already registered
   → Duplicate email
   → Solution: Use different email

❌ User not found
   → Invalid user ID
   → Solution: Check user ID
